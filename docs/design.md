## 前提

- **発売先**: Steam・DLsite（PC）が先。スマホは後。画面は 1920×1080 の横長、操作はマウス。
- **エンジン**: Godot 4.7（GDScript）。AI（Claude Code）でテキストのまま読み書きしやすいことを重視して選んだ。
- **言語**: 画面の文字・コメント・文書は日本語。

## 市場調査で分かったこと（`research/cup-ball-incremental/`）

- 「カップの玉を倍率ゲートで増やす」仕組みは、Voodoo の『Bounce and collect』（2021年）や『Cup Heroes』（2023年）などのハイパーカジュアルで広まった。Cup Heroes はパチンコ部分が自動戦闘のおまけで、レビューでは「ゲートの最善の道筋がすぐ分かる」「4時間ほどで飽きる」と言われている。
- 物理ボール×インクリメンタルの作品（Ballatory、PlinkIdle、Pegfinity など）はあるが、カップ＋ゲートを土台にしたものは見当たらなかった。
- Steam の Idler タグは急増中で、似た作品が埋もれやすい。独自の芯が要る。

## 決めたこと

### ジャンル: ローグライト（デッキ構築）
- インクリメンタル特化（放置・転生）と比べて、ローグライトに決めた。インクリの「拠点」層を重ねる案もあったが、今は入れない。
- 比べるために作った HTML の試作: A（カード式）、B（インクリ特化）、C（固定配置＋ペグ）。`web/` にある。

### 「正解がすぐ分かる」問題への対策
- ゲートを自由に並べ替えられると盤面が「解けるパズル」になるので、次の2つでゆらぎを入れた。
  - **カード式**: 毎ターン引く手札が違う。
  - **ペグ**: 盤面の釘で玉が左右に散る。
- ゲートの置き場所は、カードごとに光る候補マス（最大5つ）から選ぶ。候補は**カード1枚ごとに一度だけ抽選**し、選び直しても変わらない（選び直しで良いマスを引き直せないように）。
- 盤面は戦闘ごとにリセット。デッキはランを通して育つ。

### ×2 ゲートは「値を2倍」にする（玉を分裂させない）
- 最初は玉を分裂させていたが、画面の玉の数で結果が変わる（上限を超えると値の倍化に切り替わる）問題があった。
- ユーザーの判断で、直感的な「値の倍化」に統一した。玉の数は注いだ数のまま。

### 玉の見た目
- 値が大きいほど玉を大きく描き（対数で、上限あり）、中に数字を書く。

### 注ぎ方: カップが往復し、止めた位置から注ぐ
- 最初はマウスにカップが付いてくる形だったが、ボタンを押しに行くと狙いがずれるので、やめた。
- 「注ぐ」でカップが一定の速さで左右に往復し、クリックかスペースで止めるとそこから注ぐ。狙いが腕前になる（UFO キャッチャーに近い）。

### 最後はミニガン
- 回収した玉の値の合計を弾倉に溜め、ターンの最後にミニガンで撃つ。撃ち終わるまで勝ち負けが分からない「溜め」の時間を作るため。

### ゲートの種類
- 値: `+3`、`×2`、`x²`（関数ゲート。順番で結果が変わる）
- 経路: 跳ね返し（真上から15度、左右は玉ごとにランダム）、右へ、左へ
  - 跳ね返しは真上→45度→15度と試した。15〜30度だと上の行のゲートに届きやすい。ユーザーの判断で 15度・左右ランダム。
  - ワープは検討したが入れない（ユーザーの判断）。
- 盤面: 応援（隣の効果が2回）、充電（隣の回数 +1）
- 守り: 盾（通るたびブロック）
- 準備: 発電（決まった回数通ると次ターンのエネルギー +1）、索敵（同じく次ターンに1枚多く引く）

### 戦闘の数字（つり合いは未調整）
- エネルギー 4、手札 5（最大 9）、1ターンの玉 10、ゲートの回数 1ターン 6。（プレイヤーの HP 60 は 2026-10-24 に廃止）
- 最初はエネルギー3・候補3マスで「手狭」と感じられたので増やし、エネルギーとドローのカードも足した。

### ランの形（1章）
- 分岐する地図、11層、最上段にボス。戦闘・強敵・ショップ・休憩・宝箱。
- 敵の行動: 攻撃・連続攻撃・守り（弾を防ぐブロック）・強化・妨害（カップが速い／ゲート封印／回数減少）。頭上に次の行動を予告する。（2026-10-24 にノルマレースへ変更して廃止。上の「戦闘を『ノルマレース』に変えた」参照）
- 敵: 通常5種、強敵2種、ボス1体（ペグの王: 毎ターン、ペグの並びが変わる）。
- 成長: ゴールド、ショップ（カード・レリック・カード削除）、休憩（2026-10-24 から「強化か削除」）、宝箱（レリック）、レリック10種、カードの強化（デッキ上は id の末尾に "+"）。

### 戦闘を「ノルマレース」に変えた（2026-10-24）
経緯は [handoff-2026-10-24.md](handoff-2026-10-24.md)（ユーザーが別の AI と壁打ちしてまとめた引き継ぎ文）。
- 敵は「ノルマ（制限ターン内に与える合計ダメージ）・制限ターン・固有ハンデ」の3点で決まる。敵は攻撃してこない。
  - 理由: 敵の行動ローテーション・プレイヤー HP・ブロックは StS そのままで、このゲームの芯（盤面で玉の値を育てる）と役割が重なっていた。
- 制限ターンは仮に 通常3・強敵4・ボス5、ノルマはそれまでの敵の HP をそのまま使う（`data.gd` の定数。つり合いは後で調整）。
- **HP はなくした**（ユーザーの判断）。ノルマに届かなければ、その場でランが終わる。
- HP・ブロック系の転用:
  - 盾ゲート → 「刻み」ゲート（通るたび弾倉 +2。弾倉の倍率は受けない）
  - 防御 → 「延長」（制限ターン +1、使うと除外）
  - 応急手当、薬草袋（レリック） → 廃止
  - 鉄の小盾（毎ターン ブロック +3） → 「懐中時計」（どの戦闘も制限ターン +1）
  - 休憩所の「休む」 → 「削る（カードを1枚無料で削除）」。休憩所は「鍛える」と「削る」の2択
- 固有ハンデは、敵が盤面に常に置く**デメリットゲート**（÷2、−5、√）。見えるモノとして置く。
  - 置き場所は敵ごとに決まっていて、**地図の時点で表示する**（地図を作るときに相手を決める。点の横に印、マウスを乗せるとノルマ・制限ターン・ハンデ）。今のデッキで避けるか、あえて選ぶかを決められるように。
    - → 2026-10-24 のうちに変更: **地図には敵もハンデも出さない**（ユーザーの判断）。相手は地図を作る時点で決めるが、戦ってみるまで分からない。
  - → 2026-10-24 のうちに**二段構え**に変更（ユーザーの判断）: すべての敵が「値を減らすゲート」を持ち、そのうえで一部の敵だけが固有のハンデ（`data.gd` の `TRAITS`）を持つ。
    - 固有ハンデ: カップが速い（吹き矢の小鬼）、ゲートの回数 −2（封印の術師）、注ぐ玉 −2（鉄の巨人）、引く枚数 −1（双子の魔女）、毎ターン ペグの並びが変わる（ペグの王）。スライム・ゴブリン・岩の番人は固有なし。
  - 列を選べば大半は避けられる。反転ゲートで「小さくした値」を資産に変えることもできる（避ける余地と悪用する余地）。
  - 使用回数は自分のゲートと同じく 1ターン 6回（ユーザーの判断）。捨て玉を先に通して使い切らせる攻略ができる。
  - 隣に「応援」を置くと、敵のゲートも効果が2回になる（悪用にも自滅にもなる）。
- ボスの「毎ターン、ペグの並びが変わる」は残した。

### 盤面を 4列×5行に（2026-10-24）
- 3行 → 5行。1列のルートが深くなり、「順番で結果が変わる」が強くなる。敵のデメリットゲートを置く余白もできる。
- 盤面の縦の範囲はそのままで、ゲートの高さを 52 → 40px、行の間隔を 100px にした。ペグは行の間に5段。
- 候補マスは「**各列から空きマスを1つずつ＋ランダムに2つ**」（ユーザーの判断）。20マスだと、ランダム5つでは狙いの列に置けないことが増えるため。カード1枚ごとに一度だけ抽選するのは変えていない。

### 反転ゲートと小さい値（2026-10-24）
- **÷ のゲートをプレイヤーのカードとして入れない。** 反転と揃うまで完全に腐る（置けば自分の玉を壊し、置かなければ手札を占める）ため。除算は敵のデメリットゲートが担う。
- 反転は係数つき「C/x」の1枚完結型。生の玉（値1）を通せば 1→C で単体でも働き、育った玉が通ると小さくなるリスク系。
  - C は最初 30（強化 50）にしたが、普通に強すぎるので **6（強化 10）** に下げた（ユーザーの判断）。値は `data.gd` の反転カードの val。
- 値の下限は 0.001（`MIN_VAL`）。÷ や 1/x で 0 や無限大にならないように。
- 値が1未満の玉も対数で小さく描き、小数で値を出す（小さい玉は数字を玉の上に書く）。「玉が小さくなる→反転で巨大化」を見せ場にするため。
- 新しい + / × を増やすときは、数字の大小違いではなく「何に比例するか」（通った回数、隣のゲート数、値の桁数など）で差をつける方針。関数ゲート（x!、2^x など）はレア枠の名物として許容する。具体的な追加はユーザーに確かめてから。

### 地図をなくし、一本道にした（2026-10-24）
- 分岐する地図をやめた（ユーザーの判断）。理由: ショップや宝箱のマスがあれば、行き先を選ぶ自由がなくても成り立つ。地図は StS らしさの大きな部分でもあった。
- 11層を一本道で進む。1層目は戦闘、10層目（ボスの直前）は休憩、11層目はボス。ショップ・宝箱・強敵・もう1つの休憩は、3〜9層目のどこかにランごとにランダムで入る（`main.gd` の `_make_route`）。
- 画面上部に「ショップまで2　宝箱まで4　休憩まで6　強敵まで3　ボスまで8」のように、この先にあるものまでの層の数を出す。
- 敵やハンデは先に見せない（戦ってみるまで分からない）。
- 上部の帯が狭くなったので、レリックは「レリック 3」と数だけ出し、マウスを乗せると一覧と説明が出る。

### Slay the Spire との距離
- 戦闘のしくみ（エネルギー・行動予告・ブロック）が StS に近いのは、ユーザーは許容している。芯（盤面とゲートと玉）が違うため。
- 一方で、戦闘の外（地図・休憩・ショップ・レリック）は StS にかなり近く、気にしている。置き換えるか検討中（下の「まだ決めていないこと」）。
- 仕組みは借りてよいが、名前・文章・絵・画面の配置は自分のものにする方針。
